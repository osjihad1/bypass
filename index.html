📚 API Documentation

Authentication

All API endpoints require authentication via API key. Include your key in the request header:

X-API-Key: your_api_key_here

Endpoints

GET /api/data

Fetch data from server. Requires authentication.

GET /api/user/profile

Get current user profile information.

GET /api/stats

Get API usage statistics.

GET /api/keys

List all API keys for current user.

GET /api/logs

View request logs.

POST /api/auth/register

Register new user account.

POST /api/auth/login

Authenticate and get session token.

POST /api/keys/create

Create new API key (requires existing key).

Rate Limiting

Each API key has a configurable rate limit. Exceeding the limit will return 429 Too Many Requests.

Example Request

curl -X GET http://localhost/api/data \
  -H "X-API-Key: test_key_12345" \
  -H "Content-Type: application/json"
